# Bright House Cleaning Services — Website

Astro + TypeScript static site, ready for Netlify. Minimal JavaScript (one small script for the menu, hero slideshow, FAQ, gallery viewer and form validation).

## Run it

```bash
npm install
npm run dev       # http://localhost:4321  (development)
npm run build     # production build → dist/
npm run preview   # serve the production build at http://localhost:4321
```

## Where to edit things

| What | File |
| --- | --- |
| Phone, email, WhatsApp, social links, hours, SEO title/description | `src/data/site.ts` |
| Services, prices, FAQ, service areas, "Why choose us", steps | `src/data/site.ts` |

## Logo

The official logos live in `public/brand/` and are shown unmodified (proportions come from the SVG viewBox):

- `bright-house-logo-blue.svg` — header and light backgrounds
- `bright-house-logo-white.svg` — footer, 5-Star Promise, Meet Cindy card
- PNG versions are kept for structured data and other fallbacks

The identity manual's minimum web size is 106 × 47 px; every placement stays above it.

## Adding photos, a portrait, or a hero video

- **More photos:** add to `src/assets/photos/`, import in `src/data/photos.ts`, and add to `gallery` / `heroSlides`.
- **Cindy's portrait:** only a confirmed photograph of Cindy, used with permission. Import it in `src/data/photos.ts` and set `cindyPortrait` — it replaces the image in "Meet Cindy".
- **Hero video:** put a short muted MP4 in `public/media/` and set `heroVideo` in `src/data/photos.ts`.

## Search indexing guard

`src/data/indexing.mjs` keeps every build out of search engines (meta robots, `X-Robots-Tag` header via `dist/_headers`, and a blocking `robots.txt`) unless Netlify builds the **production** context with the official domain (`https://brighthousecleaning.ca` or `www.`) as the primary URL. Deploy Previews, branch deploys and `*.netlify.app` URLs are therefore never indexed. After connecting the domain, trigger a new production deploy to enable indexing.

Social metadata (`og:url`, `og:image`, `twitter:image`) uses the URL actually being shared: Netlify's `URL` in production, `DEPLOY_PRIME_URL` on Deploy Previews / branch deploys, and the final domain for local builds. Canonical URLs, the sitemap and JSON-LD always use `https://brighthousecleaning.ca`.

See `LAUNCH.md` for the preview, form-test, notification and launch checklist.

## Deployment (Netlify)

`netlify.toml` is configured (`npm run build`, publish `dist`). The quote form uses **Netlify Forms** (`name="quote"`, honeypot `bot-field`) and redirects to `/thank-you/`. After the first deploy, set up email notifications under *Site configuration → Forms → Form notifications* in Netlify.

The canonical domain is `https://brighthousecleaning.ca` (`astro.config.mjs` and `src/data/site.ts`).
